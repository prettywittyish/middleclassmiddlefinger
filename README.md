<h1>Reclaim Privacy Toolkit</h1>

<p>
Practical, device-level guides and civic strategies to reduce data extraction,
resist behavioral profiling, and counter the systems pushing toward centralized digital IDs.
This repository contains step-by-step privacy guides for mobile, desktop, and networks,
along with Boycott Bingo reference lists and civic action templates.
</p>

<hr>

<h2>What’s Inside (some are in progress)</h2>

<h3>Privacy Setup Guides</h3>
<ul>
  <li>Desktop browser hardening (Firefox, Brave, Librewolf, Tor)</li>
  <li>Mobile privacy for Android Firefox and iOS Firefox Focus</li>
  <li>DNS + VPN pairing (NextDNS, ControlD) with verification steps</li>
  <li>Fingerprinting resistance, uBlock Origin setups, telemetry reduction</li>
</ul>

<h3>Data-Broker Resistance</h3>
<ul>
  <li>Mass data-broker opt-outs</li>
  <li>Browser fingerprint obfuscation</li>
  <li>Synthetic noise injection techniques</li>
  <li>Dynamic pricing mitigation</li>
  <li>Metadata minimization</li>
</ul>

<h3>Boycott Bingo Lists</h3>
<ul>
  <li>Spreadsheet-ready lists of surveillance-aligned corporations</li>
  <li>Companies involved in data brokerage and behavioral targeting</li>
  <li>Alternative tools and services</li>
</ul>

<h3>Civic & Legal Action Playbooks</h3>
<ul>
  <li>FOIA templates for ALPR, Flock, and data-sharing contracts</li>
  <li>Local transparency ordinance language</li>
  <li>Guidance for federal public comments</li>
  <li>Community surveillance-audit frameworks</li>
</ul>

<hr>

<h2>Why This Exists</h2>
<p>
Data collection has moved beyond analytics and into prediction, classification,
and automated decision-making. These systems influence eligibility, pricing,
policing, and identity tracking. This toolkit helps reduce what can be collected,
distort what can be inferred, and provide pathways toward community-level
accountability.
</p>

<ul>

  <li>Civic organizers and journalists</li>
</ul>

<h2>How to Use This Repository</h2>
<ul>
  <li>Begin with desktop or mobile device hardening</li>
  <li>Add network protections through VPN + DNS filtering</li>
  <li>Apply data-broker countermeasures</li>
  <li>Use Boycott Bingo lists to apply economic pressure</li>
  <li>Deploy civic tools to create transparency and local safeguards</li>
</ul>
